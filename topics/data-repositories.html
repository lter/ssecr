Data Repositories

Tip Learning Objectives

After completing this topic you will be able to:

  • Understand the differences between generalist repositories, more specialized repositories, and search aggregators.
  • Identify some repositories “known for” particular types of data

When you start a synthesis research project, you may already have some datasets in-hand at the outset but it is likely that you will need to find more data to test your hypotheses. Research data repositories are organizations or facilities that are primarily dedicated to storing and managing research data, so they are a great place to find and access relevant data for answering your research question. There are a lot of data repositories out there. In fact, the Registry of Research Data Repositories (re3data.org) lists 3526 repositories at the time of writing, so you probably can’t search them all exhaustively. It helps to know the landscape and search efficiently.

TipA word about metadata and searching repositories

We’re about describe a bunch of repositories, and then move on to strategies for searching them. It is first worth mentioning that, while we visit repositories to access the many, many data files they contain, every repository (so far as we know) also publishes metadata describing those data. If you’ve never heard of metadata before, the quick definition is “data about the data,” or information describing a unit of data. Metadata usually contains information about:

  • who collected the data
  • what was collected
  • when, where, how and why the data were collected.

When you search in a repository or aggregator, you are not searching the data themselves, you are searching the metadata. The metadata contain essential information that let you understand the data, evaluate if they are fit for your research purpose, and use the data. So, the essential unit of data you should think about during synthesis research is the dataset — data and metadata together. Keep the dataset concept in mind as you create your synthesis data products, and remember to collect metadata.

We can categorize repositories a few different ways. Generalist repositories hold all kinds of data from all sorts of research. They tend to have fairly lax requirements for metadata and data quality, so you may have to sift through your search results carefully to determine if a dataset is fit for use. Domain-specific repositories specialize in data from a particular domain, such as a scientific discipline (e.g. environmental science or biomedical research), location (e.g. Arctic data), or research network (e.g. NEON). They tend to have higher metadata standards for the data they accept into the repository. Some repositories are also data-specific, meaning they specialize in a limited number of data types and may have strict requirements for metadata and data formatting. These differences in repository specialization can have big impacts on how much time you spend finding useful data and getting it ready to analyze.

Below we present three non-exhaustive lists of repositories that have proven useful to other synthesis projects in the past. They are broken into categories as above, and are in alphabetical order. If the “ Package” column contains the GitHub logo () then the package is available on GitHub but is not available on CRAN (or not available at time of writing).

  • Specialized repositories
  • Generalist repositories
Generalist repositories accepting a broad range of data types with minimal metadata requirements. Be aware that it can be difficult to separate the “wheat from the chaff.”
Name Description Package
Dryad A curated, nonprofit repository for data underlying scientific publications, with a focus on biosciences. Accepts any file format, applies CC0 to all submissions, and assigns DOIs. Widely used to satisfy journal data-availability requirements. rdryad
Figshare A general-purpose repository for figures, datasets, posters, preprints, and other research outputs. Minimal metadata requirements, DOIs on deposit, and a generous file-size allowance make it a quick option for supplementary materials. rfigshare
Harvard Dataverse An open repository hosting datasets across all disciplines, organized into individual “dataverses” that let projects or institutions manage their own collections. Supports versioning, DOIs, and a structured citation metadata block. dataverse
Zenodo A general-purpose repository operated by CERN, accepting any file type or discipline. Integrates directly with GitHub to archive software releases and mint DOIs, with a concept DOI that always resolves to the latest version. zen4R

Searching across repositories

If you don’t find everything you’re looking for in a particular data repository, you might want to consider a broader search across many repositories. There are a few data search aggregators out there that are quite useful for this. These services collect or index metadata from many repositories and allow you to search them in one interface. They do not always provide the data directly, instead linking out to the source repository.

Name Description Package
DataONE Aggregates environmental and ecological data from global sources, focusing on biodiversity, climate, and ecosystem research. dataone
Google Dataset Search Google Dataset Search crawls schema.org metadata published on repository landing pages to make datasets discoverable across thousands of sources at once. Useful as a starting point when the holding repository is unknown, but coverage depends on how well each repository exposes its metadata. –
OpenAIRE EXPLORE OpenAIRE is a central organization in the European Commission’s open science initiative. The EXLORE tool indexes dataset metadata from thousands of repositories, journals, registries and other sources. Data sources are worldwide, not just European. OpenAIRE
Open Traits Network The Open Traits Network has compiled an extensive lists of repositories for trait data. Check out their repository inventory for trait data. –
